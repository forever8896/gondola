How it works

One sandbox does the reading, fifty do the designing. Every sandbox is gone the moment its work is saved.

01

Read

One sandbox opens your site, copies every word and image, and measures your current look.

02

Fork ×50

Boat forks that sandbox fifty times in about a minute, so every designer starts with your site in place.

03

Direct

A curator gives each fork its own style, a wild palette and a hero idea built from your real content.

04

Build

Fifty agents design at once. Each cell of the grid shows its page live as it's written.

05

Keep

Finished pages are saved to your server. Copy any one as a Claude Code prompt to restyle your whole site.

Styles from the award directories' playbook

76 showpiece directions, each tagged with the public style categories of Awwwards and SiteInspire. Every run spreads across as many categories as it can, never the same style twice.

Category names only; no site is ever copied. Every fact on every design comes from your own page.

    Run it

    Everything runs on your machine and your accounts. Setup checks the prerequisites, writes your config and starts Postgres.

    # get it
git clone https://github.com/forever8896/gondola && cd gondola
# check Bun, Docker and Boat, write .env, start Postgres
bun run setup
# open http://localhost:8787 and enter a domain
bun run start
